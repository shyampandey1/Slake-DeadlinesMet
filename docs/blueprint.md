# **App Name**: DeadlinesMet

## Core Features:

- Task Definition: Allow user to define a single task with a name.
- Deadline/Duration Setting: Enable user to set a deadline or a duration for the task.
- Timer Display: Display a minimalist, full-screen timer showing the task and remaining time.
- Timer Controls: Include standard timer controls: Pause, Resume, End.
- Completion Alert: Provide a completion alert (sound/vibration) with a "Did you complete it?" prompt.
- Task History: Locally store task history (Task Name, Duration, Completion Status).
- Motivational Messages: Upon successful completion, display encouraging messages generated using a prompt tool and current and past task data.

## Style Guidelines:

- Primary color: HSL(40, 90%, 50%) translated to bright gold (#F2B60D) to promote focus and productivity.
- Background color: HSL(40, 20%, 95%) translated to very light beige (#F7F4EF) for a calm and unobtrusive backdrop.
- Accent color: HSL(10, 80%, 40%) translated to deep reddish-orange (#B3390D) to draw attention to important CTAs.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, techy feel.
- Body font: 'Nunito' (sans-serif) for a clean and readable interface.
- Clock font: A digital font like a modern clock display.
- Use simple, minimalist icons to represent timer functions and settings.
- Maintain a clean, distraction-free layout to enhance focus. Emphasize the timer display for maximum visibility.
- Use subtle animations for timer transitions and alerts to provide visual feedback without being disruptive.
- Circular rounded corners modern style
